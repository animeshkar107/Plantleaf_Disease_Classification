# Dataset Information

**Dataset Name:** PlantVillage

**Source:** Kaggle

**Dataset Identifier:** emmarex/plantdisease

**Dataset Link:** https://www.kaggle.com/datasets/emmarex/plantdisease

- Total Images: 20,638
- Number of Classes: 15
- Original Image Dimensions: 256 × 256
- Training Images: 16,511
- Validation Images: 4,127
- Train-Validation Split: 80:20

The dataset contains images of healthy and diseased
pepper, potato, and tomato leaves.

The dataset is not included in this repository.
Please download it from the original Kaggle source.
